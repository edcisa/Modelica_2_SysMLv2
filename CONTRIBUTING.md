# Contributing Guide

Thank you for considering contributing to Modelica2SysMLv2!

## How to Contribute

- Fork the repository and create your branch from `main`.
- Ensure code is formatted with `black` and passes `ruff` and `mypy`.
- Add tests for new features and ensure all tests pass (`pytest`).
- Document new modules and update the README if needed.
- Submit a pull request with a clear description of your changes.

## Code of Conduct

Please note we have a [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you agree to abide by its terms.

## Reporting Issues

- Use GitHub Issues for bug reports and feature requests.
- Please provide as much detail as possible.

## Contact

For major changes or questions, open an issue or contact the maintainers.
